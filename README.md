# Pepper Spray (Fabric 1.20.1)
Hold right-click: unlimited orange mist; hit targets get Poison + Slowness II + Blindness for 5s.
Build: push to GitHub -> Actions tab -> download artifact `pepperspray-mod` (the .jar).
Requires Fabric API in the game.

First person: a hand (with thumb on the button) is shown holding the can. Tweak position/angle in
`models/item/pepper_spray_hand.json` -> display.firstperson_righthand (translation / rotation / scale).
